## ข้อสังเกต

- ผลจากเว็บสอดคล้องกับการคำนวณอิสระภายใต้แบบจำลองเดียวกัน (ผ่านเกณฑ์ A3)
- VCE = 8.052 V อยู่ห่างจากเกณฑ์ Saturation (0.3 V) มาก → รายงานเป็น ACTIVE โดยไม่มีข้อจำกัดเพิ่ม
- ถ้าเปลี่ยน RC ให้ใหญ่พอจน VCE ≤ 0.3 V เว็บจะขึ้นป้าย SATURATION และข้อความเตือนว่าค่าไม่น่าเชื่อถือ (ผ่านเกณฑ์ A5)
- ถ้า R2 เล็กเกินจน VTH ≤ VBE เว็บจะขึ้นป้าย CUTOFF และรายงาน IC = 0 (ผ่านเกณฑ์ A5)
